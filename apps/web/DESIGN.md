# Running Man 设计系统 2.0

> 唯一真源是 `apps/web/app/globals.css`。文档里每个双主题颜色、字号、间距、阴影都必须与 stylesheet 中的 `:root`（日间）与 `.dark`（夜间）声明一致，`scripts/check_design_tokens.py` 会把本节所有 token 表格与 stylesheet 逐行比对；`scripts/check_contrast.py` 会在日间与夜间两套表面上校验 WCAG AA 对比度。组件里永远不写裸十六进制色值——先加 token，再用 token。

---

## 1. 产品与双主题定位

Running Man 是一个人的运动科学训练驾驶舱。数据从 Intervals.icu 读进来，页面要回答的问题只有一个：现在该干什么，以及为什么。

产品支持**双主题丝滑切换**，两套色盘在 OKLCH 空间内保持恒定色相角（Hue），按背景明度自适应平移：

- **夜间遥测（Precision Night Telemetry · `.dark`，默认）**：面向破晓晨跑前速览、夜跑后复盘及户外强光下高反差读取。深邃碳黑画布 + 顶边微镜面卡片 + 自发光生物遥测曲线。
- **日光图谱（Daylight Chrono Lab · `:root`）**：受精密计时器与瑞士田径秩序图谱启发，面向日间室内桌面深度复盘、周期计划编排与截图分享。矿物冷灰画布 + 纯白图版卡片 + 深碳墨数字 + 油墨级曲线。

文案口径是运动员对教练说话：给具体数字，不给形容词。「本周 TSS 412，比上周多 38，CTL 涨到 62」，而不是「训练量有所提升」。中文照常写，指标缩写保持拉丁字母——TSS、CTL、ATL、TSB、ACWR、HRV、VO2max、e1RM 不翻译、不音译、不加括号注释。

三条语气规则：

1. **先给结论，再给依据。** 首屏第一句是判断，紧接数字与图表依据，核心判断不默认折叠。
2. **数字必须带单位和时间范围。** 「TSS 412」不合格，「本周 TSS 412（10-14 至 10-20）」合格。
3. **缺数据就说缺数据。** 写「未记录」或「样本不足」，不写 0，不写 `--` / `—`，缺失时隐藏单位。

## 2. 信息层级与页面问题

层级按变化速度排，变慢的在上，变快的在下：

| 层 | 变化速度 | 装什么 | 渲染位置 |
|---|---|---|---|
| 身份 | 月级 | 姓名、跑力等级、目标赛事、PB | 个人页与首屏状态行 |
| 状态 | 日级 | 就绪分数、HRV、静息心率、TSB、ACWR | 首屏恢复信号卡与负荷卡 |
| 行动 | 每次 | 今天练什么、教练判断、距离、配速、时长 | 一屏一张焦点行动卡 |
| 计划 | 周级 | 本周课表、计划与实际偏差 Δ、周负荷目标 | 日历周视图、月视图 |
| 趋势 | 周级 | PMC、CTL/ATL/TSB 曲线、基线走廊、VO2max | 图表区 |
| 提示 | 事件 | 同步进度、动态调整建议、数据缺口 | 状态行与提示卡 |

### 2.1 页面与主问题

| 页面 | 主问题 | 首屏给什么 |
|---|---|---|
| 首页 | 今天该怎么练，身体顶不顶得住 | 教练判断结论、48px 主焦点数字、待确认计划调整、恢复信号与短期负荷 |
| 日历 | 本周还剩什么没做，做的和计划的差在哪 | 本周执行摘要、按天排列的课表与计划/实际偏差 Δ |
| 训练记录 | 这段时间练了多少 | 顶部四格汇总、多维筛选与已生效筛选胶囊、记录列表 |
| 活动详情 | 这一次跑得怎么样 | 4 格核心读数、负荷刻度、运动流曲线与 GPS 轨迹、分段配速与区间占比 |
| 分析 | 这段时间的训练哪里对、哪里不对 | 先给基于真实数字的本期解读，再给多指标对照图（带生理基线走廊） |
| 目标 | 离目标还有多远，现有训练撑不撑得住 | 待确认调整建议、环形完成度、剩余周数与负荷推演 |
| 力量训练 | 今天练了多少容量，肌群平衡怎样 | 实时动作/组数/容量汇总、肌群占比条与 e1RM 趋势 |
| 我的 | 我目前的训练水平和身体状态如何 | 身份、当天与需处理的提醒、PB 四格、只读生理指标、训练区间；跑鞋与比赛成绩有记录时才出现 |
| 设置 | 怎样调整系统使用的个人信息、外观与数据源 | 界面外观（日/夜/跟随系统）、生理参数、训练区间、数据源与历史回填 |

首页、日历、分析、目标、我的是五个主导航入口（`shared/config/nav-config.ts`）。我的页侧重跑者状态展示，设置页通过我的页或数据状态入口进入；训练记录、活动详情与力量训练作为深层工作流页面，共享对应主导航激活态。

首页按使用顺序展示今日训练、恢复信号、一行负荷结论与本周进度。桌面端在左栏展示训练安排与周进度，右栏展示恢复和负荷结论；手机端保持同一阅读与键盘访问顺序。训练记录列表按运动员时区的日期分组，每条活动展示运动类型、名称、强度、主要读数和详情入口。分析页在图表之前展示可切换的观察周期。

## 3. 画布与三级容器层级

层次通过**明度阶梯 + `1px` 低对比度外发丝边 + 顶边微高光**建立，彻底弃用装饰性渐变与斑点纹理：

| 级别 | 表面 Token | 圆角 | 用途 |
|---|---|---|---|
| 全局画布 | `--color-surface-sunken` | — | L0 底层画布，承载页面栅格 |
| 卡内下沉槽 | `--color-surface-overlay` | 10px（`rounded-xl`） | L1 `InsetBlock` 分组槽，**无边框** |
| 内容卡 | `--color-surface-card` | 12px（`rounded-2xl`） | L2 图表、列表、目标、活动对象（`p-5`，1px 发丝边 `--color-border-subtle`） |
| 焦点行动卡 | `--color-surface-raised` | 12px（`rounded-2xl`） | L3 一屏最多一张，配 `--shadow-panel` 与强调描边 |

规则：

- **行动卡一屏最多一张。** 它是全站唯一使用 `--shadow-panel` 的常驻卡片。
- **卡片不嵌套。** 卡内分组一律用 `InsetBlock`（L1 下沉槽，无边框），绝不在卡内再画一层外框。
- **弹层单独使用浮层阴影。** 对话框、下拉菜单用 `--shadow-elevated`，底部抽屉用 `--shadow-sheet`。
- **一屏一处 `48px` 主焦点数字。** 其余指标使用 `30px` 或 `20px` 阶梯。

## 4. 色彩系统（日间 / 夜间双主题契约）

全部 token 声明于 `apps/web/app/globals.css` 的 `:root`（日间）与 `.dark`（夜间），经 `@theme inline` 暴露给 Tailwind。**组件里永远不写裸十六进制色值。**

### 4.1 10% 荧光克制法则与双通道映射

- **荧光黄绿（Track Volt）只占界面 5%–10%**：仅用于主 CTA 按钮填充、分段/导航滑动指示条、今日主焦点状态点与可交互链接。**所有常规核心统计数字使用高对比主墨色 `--color-text-primary`**，不用荧光绿涂满数据数字。
- **填充通道 vs 前景通道分离**：主填充 `--color-accent` 在日间维持标志性赛道黄绿（`oklch(0.87 0.20 124)`），上面配深墨文字 `--color-on-primary`；而可交互文本链接 `--color-accent-strong` 在日间自动下潜为深林竞技绿（`oklch(0.38 0.135 135)`），确保白底对比度远超 4.5:1。

## 5. 7 档运动遥测字阶

三套拉丁字体严格分工：拉丁正文 `Space Grotesk`，指标数字与等宽表格列 `JetBrains Mono`（`.num` 绑定 `--font-mono`），英文大写标签 `Barlow Condensed`。三者在 `app/layout.tsx` 都以 `display: "optional"` 加载：首帧前未就绪就整页使用度量对齐的系统后备字体，首帧之后不再换字形。中文正文与中文标题用 `Noto Sans SC`（`--font-sans` 首位），它按 unicode-range 分片并以 `swap` 加载：分片晚到时同一句中文不能出现两种字形，所以不用 `optional`。

| Token | 值 | 行高 | 用途 |
|---|---|---|---|
| `--text-metric-xl` | `3rem` | 1 | 48px 全屏唯一主决策数字 |
| `--text-metric-lg` | `1.875rem` | 1.08 | 30px 一级卡片核心读数 |
| `--text-display-sm` | `1.625rem` | 1.25 | 26px 页面主标题与结论判断句 |
| `--text-title2` | `1.25rem` | 1.3 | 20px 读数带数值与卡内小标题 |
| `--text-body` | `1rem` | 1.55 | 16px 教练解读与正文 |
| `--text-subheadline` | `0.875rem` | 1.45 | 14px 高密度表格行、筛选器与按钮文字 |
| `--text-caption1` | `0.75rem` | 1.4 | 12px 中文最小地板：标签、单位、时间戳与出处 |

规则：

- **中文不小于 12px。** `--text-caption2`（11px）只给纯拉丁数字/英文缩写使用。
- **`.num` 仅用于数字读数。** 中文 `<h1>` / `<h2>` 不挂载 `.num`，避免等宽英文体干扰中文标题字重。
- **缺值隐藏单位。** 值为「未记录」或「样本不足」时，不渲染 `km` / `bpm` / `/km` 单位。

## 8. 图表规范

每张图四个要素，缺一不画：

1. **标题与范围** — 说明回答什么问题，标注日期起止。
2. **基线参考走廊（`referenceBand`）** — 对 ACWR（`0.8–1.3`）、TSB 等区间敏感指标，绘制半透明参考带。
3. **遥测读数栏** — 默认展示最新点读数与周期变化；悬停或点选展示：**① 当天数值（带单位） · ② 差值 Δ · ③ 基准对比**。
4. **出处与无障碍摘要** — 底部一行标明 `数据来源：Intervals.icu · 起止日期`；每条序列的首尾值与拐点摘要只给读屏（`sr-only`），键盘用户按「查看数据」展开 `ChartDataSummary` 数据表。图表不显示「移动指针查看」这类操作提示。

空数据不画坐标系，直接收起并说明缺失原因。图表颜色全部通过 `shared/lib/chart-tokens.ts` 响应式读取 CSS 变量，主题切换时自动热重绘。

## 9. 双主题切换与动效规范

- **零闪烁启动**：`app/layout.tsx` 注入同步脚本读取 `localStorage("rm.theme")`（`"dark" | "light" | "system"`，默认 `"dark"`），首帧绘制前即确定 `.dark` 与 `meta[name="theme-color"]`。
- **空间圆形扩散切换**：支持 `View Transitions API` 且未开启 `prefers-reduced-motion` 时，切换期间挂载 `data-theme-switching` 冻结元素级 `transition`，并以点击坐标为圆心做 `280ms` 径向揭示动画；快捷键 `Alt+T` 可全局瞬切。
- **路由切换只做透明度交叉淡入，不做位移**：主导航五个 `<Link>` 完整预取（`prefetch`），`(dashboard)/loading.tsx` 提供与 `Page` 页头和内容卡同结构的路由级骨架，所以导航提交时不再等待源站。浏览器接管 View Transition 时旧快照与新页面等长交叉淡入；未接管时（Firefox、旧版 Safari、后退手势）由 `RouteArrival` 做同长的 `.route-arrival` 淡入；两者互斥，由挂载时 `data-route-vt` 是否存在决定。
- **数据切换保留上一组数据**：`SWRProvider` 开启 `keepPreviousData`，并把 `isLoading` 收窄为「请求进行中且没有任何可展示的数据」。切周期、切 Tab、切周时内容不回到骨架屏，新数据到达后原地更新（ECharts 按 260ms 插值）。
- **骨架到内容只淡入**：骨架与内容结构一致（首页 `HomePortraitSkeleton` 与仪表盘同栅格），内容容器挂 `.content-arrival`，通过 `@starting-style` 在首次挂载时从透明淡入，不触碰布局。
- **点按反馈三套语言，按下 80ms 到位**：可交互控件 `.tactile`（缩放 0.975）、列表行 `.row-press`（底色）、其余按钮与链接在触屏上由全局规则按下变淡；`Button` 的 `active:duration` 为 75ms，松开回到 150ms。
- **克制动效 Token**：

| Token | 值 | 用途 |
|---|---|---|
| `--duration-instant` | `100ms` | 颜色反馈（也是 Tailwind transition 工具类的默认时长）、退场 |
| `--duration-press` | `80ms` | 按下到位 |
| `--duration-fast` | `180ms` | 常规状态变化、路由入场、骨架到内容淡入 |
| `--duration-normal` | `300ms` | 进度条与抽屉 |
| `--duration-slow` | `600ms` | 进度环扫描 |
| `--duration-focal` | `520ms` | 首页主决策数字一次遮罩揭示 |
| `--default-transition-duration` | `100ms` | 未显式写 duration 的 transition-colors 等工具类，取 --duration-instant |
| `--ease-default` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 点按与颜色 |
| `--ease-enter` | `cubic-bezier(0.16, 1, 0.3, 1)` | 进场与主题扩散 |
| `--ease-exit` | `cubic-bezier(0.7, 0, 0.84, 0)` | 退场 |

## 10. 断点、响应式网格与触控

| 断点 | 宽度 | 布局 |
|---|---|---|
| 手机竖屏 | `< 768px` | 单栏流式，`max-w` 自适应，底部 5-Tab 导航栏 |
| 手机横屏 | `orientation: landscape` & `max-height: 500px` | 压缩底栏至 `40px` 纯图标，弹层转居中模态 |
| 平板竖屏 | `768px – 1023px` | 居中内容列，局部两列网格 |
| 桌面端 | `>= 1024px` | `--shell-content-max` 扩展至 `64rem`（`1024px`），双栏遥测布局，底部居中悬浮命令坞（`max-w-2xl`）+ 数字键 `1–5` 导航 |

- **零横向溢出**，**可点区域不小于 44×44px**。

## 11. 禁止清单

- 未经 `globals.css` 声明的裸十六进制色值或 Tailwind 原生调色板类名。
- 把 `--color-accent` 荧光绿用作大面积非交互统计数字墨色。
- 内容面板使用装饰性径向波点渐变或 `backdrop-filter`（仅导航与粘性顶栏 chrome 允许半透明模糊）。
- 卡片嵌套卡片（卡内分组一律用 `InsetBlock`）。
- 一屏两张焦点行动卡。
- 11px（`text-caption2`）承载中文字符。
- 缺失数据写 `0` / `--` / `—`，或在「未记录」后拼接单位。
- 路由入场带位移（上移、推入）；底部 Tab 之间切换只允许透明度变化。
- `loading ? <Skeleton/> : <Content/>` 之间不做淡入，或骨架结构与内容结构无关。
- 算法注释、口径说明、免责声明写成页面正文；它们进 `MetricInlineDisclosure`，正文只留一句结论。
- 同一指标在一页出现两次以上：判定词、参考区间、解释只写一次。
- 没有数据的区块占一张卡；空态收成一行入口，或等有记录再挂载。
- 列表行渲染审计段落（分类依据、置信度、一致性校验留在详情页）。
- 文字链接各自拼写箭头与下划线；离开当前页才带箭头，统一用 `TextLink`。
- 提醒条进首页决定页；提醒只在「我的」页展示当天生成或需要处理的条目。
