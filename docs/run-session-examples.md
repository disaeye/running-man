渐加速示例：

```
渐加速跑 · 有氧：连续 10.00 km；分段配速 6:10 → 5:45 → 5:20/km；低强度域占比 78%；后段进入中等强度域；刺激有氧耐力与配速控制。
```

完成课程的一行课程表达加质量指标：

```
间歇跑 · 阈值，末段进入高强度：8 × 1.00 km（实测 0.93–1.00 km，4:49–5:50/km） + 1 × 0.57 km（4:28/km）[恢复 43 s / 0.11 km]；工作里程 8.41 km；整场 8.52 km；证据等级 B。
```

IAAF 1997 记号 `reps × distance (pace) [recovery]` 在目标条款中展开为 `组数 × 轮数 × 单轮距离（目标配速）[恢复]`。当前实现的课程主体按这一格式输出；轮数取实际工作段数，单轮里程取对应工作段实测里程。

## 五对象与质量指标

每个分类对象包含 `session_classification`、`prescription`、`execution`、`quality`、`evidence`。
`prescription.segments` 与 `execution.segments` 使用相同的字段定义：计划侧写入 `target`，完成侧写入 `measured`；每行都带 `pace_s_km`、`avg_hr`、`domain`、`evidence_source`。
计划保留自身分段边界，完成记录保留实测分段边界；`quality.per_segment_differences` 覆盖两侧全部行，额外实测段写入 `paired=false` 的未配对行，`unpaired_segment_count` 记录数量。
`quality` 同时写入刺激目录声明的 `low_domain_share`、`time_in_domain_s`、`peak_speed_attainment`、`stride_consistency`、`monotonicity`、`speed_increase_pct`、`last_domain_match`。

展示层输出一行课程表达，紧跟一组质量指标：

```
证据 B；置信度 0.77；工作里程完成度 0.90；结构匹配 0.56；配速达成 0.96；工作配速波动 0.03；恢复/工作 0.73
```

## 权威表达依据

- IAAF 1997：`sets × reps × distance (pace) [recovery]`。
- ACSM/ESSA 2025：FITT(VP)、四个生理强度域、五档强度术语、固定百分比与 RPE 的局限。
- World Athletics：低强度跑、间歇课示例与恢复表达。
- Haugen 2021：阈值间歇、VO₂max 间歇、短冲刺间歇的工作时长、恢复时长与典型总量。
- Intervals.icu `?intervals=true`：精确分段边界。
- Daniels VDOT：E/M/T/I/R 配速。
